# Учёт рабочего времени в 1С:Документооборот

![1С:Документооборот КОРП 3.0](./1C-Документооборот%20КОРП%203.0.png)

Учебный проект по расширению функциональности **1С:Документооборот КОРП 3.0** для учёта рабочего времени сотрудников по проектам.
## О проекте
Проект объединяет загрузку ежедневных отчётов и анализ трудозатрат в 1С. Сотрудник заполняет отчёт по шаблону Excel и загружает данные в систему. Руководитель использует дашборд, чтобы сравнивать плановые и фактические часы, видеть загрузку сотрудников и отслеживать статус отчётности.

## Цель проекта

Упростить подготовку ежедневных отчётов и дать руководителю возможность видеть, сколько часов запланировано и сколько фактически затрачено по каждому сотруднику и проекту.

## Возможности MVP

Проект предусматривает:

- **Загрузку из Excel.** Данные из файла по шаблону загружаются в ежедневный отчёт в 1С.
- **Дашборд трудозатрат.** Плановые и фактические часы, отклонения, загрузка сотрудников и детализация по проектам отображаются на одном экране.
- **Выгрузку в PowerPoint.** Данные дашборда можно выгрузить в презентацию для обсуждения результатов.

## Что показывает дашборд

| Блок | Содержание |
| --- | --- |
| Сводные показатели | Плановые и фактические часы за выбранный период и отклонение от плана |
| Структура рабочего времени | Распределение фактических часов по проектам |
| Детализация | Трудозатраты и загрузка по сотрудникам, трудозатраты по проектам |
| Статусы и отклонения | Статусы ежедневных отчётов и позиции, по которым факт отличается от плана |
